# OOP Car Dealership System

This project is a simple **Object-Oriented Programming (OOP)** application developed in **Java** that simulates a basic vehicle dealership system.

## Features
- Management of **Customers** and **Sellers**
- Different types of vehicles: **Car** and **Van**
- Use of **inheritance** with an abstract `Vehicle` class
- **Polymorphism** and **casting** to access subclass-specific methods
- **Aggregation** between `Seller` and multiple `Customer` objects using `ArrayList`
- Basic **encapsulation and validation** in setters

## Technologies
- Java
- Object-Oriented Programming concepts
- UML design
